# ISL-CSLRT Pipeline

This repository provides preprocessing and training code for the Indian Sign Language Continuous Sign Language Recognition and Translation (ISL-CSLRT) dataset.

## ⚠️ Data Disclaimer
This repository **does not host, redistribute, or include the ISL-CSLRT dataset itself**. Users must obtain the dataset directly from its original authors and comply with their licensing terms. 

- **Primary Source (DOI):** [Mendeley Data - 10.17632/kcmpdxky7p.1](https://data.mendeley.com/datasets/kcmpdxky7p/1) (Listed as CC BY 4.0 by R. Elakkiya and B. Natarajan)
- **Secondary Source:** [Kaggle - drblack00](https://www.kaggle.com/datasets/drblack00/isl-csltr-indian-sign-language-dataset)

## Documentation
Please see the [Preprocessing Pipeline README](preprocessing_v2/README.md) for detailed instructions on the dataset splits, configuration, and the Leave-One-Signer-Out (LOSO) cross-validation protocol.
